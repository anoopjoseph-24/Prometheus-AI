# Prometheus-AI
Prometheus AI is a Retrieval-Augmented Generation (RAG) based website intelligence platform that can ingest any website URL, recursively crawl linked pages, build a knowledge base, and answer user questions using contextual information retrieved from the website.

# Planned features
  web crawling
  website content and context extraction
  text chunking intelligently
  vector embedding
  rag powered chatbot
  website summary
  FAQ generation
  ....
